# YTWash 0.3.0-beta

- Shift+N follows YTWash creator order, matching the Next button.
- The native Next preview shows the next queued video's thumbnail.
- A red lightning icon appears beside the keyboard shortcut to identify YTWash ordering.
- Native previews return when grouping is disabled; shortcuts leave typing fields alone.
- Existing local video reminders, save/resume, grouping, and optional cleanup remain available.

## Downloads

- `ytwash-v0.3.0-beta.zip`: Chrome / Edge, load unpacked.
- `ytwash-v0.3.0-beta-firefox.zip`: Firefox, temporary unsigned add-on.
- `ytwash-v0.3.0-beta-publishing-assets.zip`: branding, not an extension.
- Each archive includes a SHA256 checksum.

Keep the same installation to retain local data. Reload the extension and refresh YouTube tabs after updating. This beta is distributed through GitHub; browser tests use simulated YouTube pages. The display/package version is `0.3.0-beta`, and the numeric extension version is `0.3.0`.
