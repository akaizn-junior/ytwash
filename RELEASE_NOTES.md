# YTWash 0.3.0-beta

- Shift+N and the Next button follow YTWash’s creator order.
- The native Next preview shows the next video’s thumbnail and a red lightning icon beside the shortcut.
- One-time Watch Later reminders: Later today, In 3 days, In a week, or Choose a date and time.
- Set and cancel reminders in Options or set them from the video’s menu. Menus match YouTube in light and dark mode.
- Finished videos cancel their reminder. Repeating reminders and the separate saved-video queue have been removed.
- Existing save/resume, creator grouping, and optional playlist cleanup remain available.

## Downloads

- `ytwash-v0.3.0-beta.zip`: Chrome / Edge, load unpacked.
- `ytwash-v0.3.0-beta-firefox.zip`: Firefox, temporary unsigned add-on.
- `ytwash-v0.3.0-beta-publishing-assets.zip`: graphics, not an extension.
- Archives include SHA256 checksums.

Keep the same installation, reload YTWash, and refresh YouTube after updating. Reminders need a running browser and enabled notifications. This beta is unsigned; automated browser tests use simulated YouTube pages.
