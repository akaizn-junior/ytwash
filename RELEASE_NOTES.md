# YTWash 0.2.0-beta

- Automatic, opt-in Watch Later reminders configured in Options.
- Custom reminder intervals from 1 to 365 days, defaulting to weekly.
- Local Save for later queue works without a YouTube or YTWash account; manage saved videos in Options.
- Notifications rotate through unwatched saved videos. Finished videos stop being suggested, and clicking a reminder opens the video.
- Existing save/resume, creator grouping, and optional playlist cleanup remain available.

The package and display version are `0.2.0-beta`; browser manifests use numeric version `0.2.0`. Beta versions have no numbered suffix.

## Downloads

- `ytwash-v0.2.0-beta.zip`: Chrome / Edge, load unpacked.
- `ytwash-v0.2.0-beta-firefox.zip`: Firefox, temporary unsigned add-on.
- `ytwash-v0.2.0-beta-publishing-assets.zip`: branding, not an extension.
- Archives include SHA256 checksums.

Keep the same installation to preserve local data. Reload the extension and refresh YouTube tabs after updating. Reminders need a running browser and enabled system notifications. This beta is unsigned and distributed through GitHub; automated browser tests use simulated YouTube pages.
