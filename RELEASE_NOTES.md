# YTWash 0.1.0 beta 1

First beta prerelease of the existing 0.1.0 line, built from the current GitHub source after the alpha releases. The extension's numeric version remains 0.1.0; its display version is 0.1.0-beta.1.

- Save through YouTube's native Save control and resume from locally saved playback positions.
- Group playlists by creator, including the watch-page sidebar, and follow that order with native playback controls.
- Opt into cleanup of completed videos through native playlist controls.
- Open extension Options from the toolbar.

## Downloads

- `ytwash-v0.1.0-beta.1.zip`: Chrome and Edge, load unpacked.
- `ytwash-v0.1.0-beta.1-firefox.zip`: Firefox, temporary unsigned add-on.
- `ytwash-v0.1.0-beta.1-publishing-assets.zip`: existing branding and store graphics, not an installable extension.
- Each archive has a corresponding SHA256 checksum.

Keep the same extension installation when updating to preserve locally saved positions and preferences. Reload the extension and refresh YouTube tabs after replacing the files.

This is an experimental GitHub beta, not a Chrome Web Store publication or a signed Firefox add-on. Browser checks use simulated YouTube pages; signed-in YouTube behavior may vary. Cleanup is optional and changes your playlist; keep it off when first trying the beta.
