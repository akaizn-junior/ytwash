# YTWash 0.3.1-beta

- Choose **Remind me to watch** in a video’s menu to schedule immediately. Later today is the default; no time picker appears on YouTube.
- Reminder actions now cover video cards, playlists, the watch-page sidebar and actions, and Shorts, including videos outside Watch Later.
- Change the default timing in Options. Custom dates are remembered; expired dates fall back to later today.
- Native YouTube menu styling, notification actions, reminder cancellation on completion, and saved timestamps remain available.

## Downloads

- `ytwash-v0.3.1-beta.zip`: Chrome / Edge, load unpacked.
- `ytwash-v0.3.1-beta-firefox.zip`: Firefox, temporary unsigned add-on.
- `ytwash-v0.3.1-beta-publishing-assets.zip`: branding, not an extension.
- Each archive includes a SHA256 checksum.

Keep the same installation to retain local data. Reload the extension and refresh YouTube tabs after updating. Browser tests use simulated YouTube pages; live signed-in YouTube remains to be verified. Notifications require browser/system notification permission. Display/package version: `0.3.1-beta`; numeric extension version: `0.3.1`.
