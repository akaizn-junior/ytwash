Make Watch Later manageable

Less searching. More watching.

YTWash adds simple controls to the YouTube pages you already use. No separate dashboard or duplicate playlist.

01 / ORGANIZE

Group by creator

Find, sort, and explore videos from the same channel. Use “Index more” when YouTube has not loaded the whole playlist.

02 / KEEP WATCHING

Play in sequence

Play the currently indexed videos from one creator in order. Stop the temporary queue whenever you want.

03 / PICK UP AGAIN

Save your place

Save a video timestamp locally and return to that point in the same browser profile.

Optional automatic cleanup: When enabled, YTWash can attempt to remove finished videos from Watch Later through YouTube's controls. This experimental option is off by default. Keep it off for your first test.
Getting started

Install the alpha in minutes.

YTWash is distributed directly through GitHub while it is experimental. You don't need a YTWash account.

Open GitHub Releases and download the latest ytwash-*.zip under Assets—not the source code ZIP.
Extract the ZIP into a folder. Keep the extracted folder on your computer.
Open chrome://extensions (Chrome) or edge://extensions (Edge). Enable Developer mode and choose Load unpacked.
Select the extracted folder containing manifest.json. Open or refresh YouTube Watch Later.

Firefox support is being tested. The GitHub ZIP is not a signed Firefox add-on and cannot be installed permanently as a normal add-on.
